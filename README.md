# 基于大数据的中式早餐店订单数据分析及可视化系统

## 项目简介

本项目是一个基于Dash的中式早餐店订单数据分析及可视化系统，旨在为餐饮零售业的精细化运营提供数据驱动的决策支持。系统采用一体化架构，前端和后端集成在Dash框架中，通过Pandas进行数据处理和分析，使用Plotly实现交互式数据可视化，实现了从数据采集、处理、分析到可视化展示的全链路解决方案。

## 核心分析功能

### 1. 早高峰时段分析
- 分析6:00-10:00早高峰时段的销售情况
- 按小时统计销售额、订单数、销售数量
- 计算早高峰销售占比
- 识别最繁忙时段，优化人员排班

### 2. 菜品销量排行
- 统计各菜品的销售数量、销售金额、订单数
- 计算平均单价，分析菜品定价合理性
- 提供Top 20热销菜品排行
- 帮助商家优化菜品结构

### 3. 堂食/外卖渠道对比
- 对比堂食和外卖渠道的销售数据
- 分析各渠道的销售额、订单数、销售数量
- 计算各渠道销售占比
- 帮助商家制定渠道策略

### 4. 客单价分析
- 计算平均客单价、中位数客单价
- 分析客单价分布（0-10元、10-20元、20-30元等）
- 识别高价值订单特征
- 帮助商家提升客单价

### 5. 复购用户分析
- 统计复购用户数量和占比
- 分析用户购买频次分布
- 识别高价值客户
- 帮助商家制定会员营销策略

### 6. 周报导出
- 自动生成上周销售报告
- 包含爆款商品、日销售汇总等
- 支持Excel格式导出
- 方便商家定期复盘

## 扩展功能

### 销售预测
- 基于历史数据预测未来销售趋势
- 帮助商家提前做好库存准备

### 商品关联分析
- 发现经常一起购买的商品组合
- 优化套餐搭配和推荐策略

### 客户分群
- 根据消费行为对客户进行分群
- 实现精准营销

**说明**：这些功能为系统扩展功能，可根据需求进一步开发

## 核心模块说明

### 1. dash_app.py - Dash主应用
- **功能**：定义所有页面布局和交互逻辑
- **关键组件**：
  - KPI指标卡片：总销售额、今日销售额、客单价
  - 销售趋势图：展示销售趋势变化
  - 时段销售分布：分析不同时段的销售情况
  - 热销商品排行：展示Top商品
  - 高级分析功能：销售预测、商品关联分析、客户分析

### 2. database.py - 数据库操作和数据分析模块
- **功能**：封装所有数据库操作和数据分析逻辑
- **核心函数**：
  - `get_morning_peak_analysis()` - 早高峰时段分析
  - `get_dish_ranking()` - 菜品销量排行
  - `get_channel_comparison()` - 堂食/外卖渠道对比
  - `get_order_value_analysis()` - 客单价分析
  - `get_repeat_customer_analysis()` - 复购用户分析
  - `export_weekly_report_to_excel()` - 周报导出

### 3. chart_generator.py - 图表生成模块
- **功能**：生成各种交互式图表
- **图表类型**：
  - 折线图：销售趋势
  - 柱状图：时段销售、热销商品
  - 饼图：销售结构占比
  - 散点图：商品关联分析

### 4. analytics.py - 高级数据分析模块
- **功能**：实现高级数据分析算法
- **核心功能**：
  - 销售预测：基于历史数据预测未来销售
  - 商品关联分析：发现经常一起购买的商品组合
  - 客户分群：根据消费行为对客户进行分群

## 数据库设计

### 主要数据表

#### 1. products（商品表）
- 存储商品基本信息，包括名称、分类、价格等

#### 2. orders（订单表）
- 存储订单信息，包括订单号、订单时间、总金额、渠道等

#### 3. order_items（订单明细表）
- 存储订单明细，关联商品和订单

#### 4. users（用户表）
- 存储系统用户信息，包括用户名、密码、角色等

## 安装和运行

### 1. 环境要求
- Python 3.8+
- MySQL 5.7+

### 2. 安装步骤

```bash
# 1. 克隆项目
git clone [项目地址]
cd breakfast

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. 安装依赖
pip install -r requirements.txt

# 5. 配置环境变量
# 复制.env.example为.env，并填写数据库配置
cp .env.example .env

# 6. 初始化数据库
python seed_data.py

# 7. 运行Dash应用
python dash_app.py
```

### 3. 访问系统
- 系统主页：http://localhost:8050
- 自动刷新：每60秒自动更新数据
